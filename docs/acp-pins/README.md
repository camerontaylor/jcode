# Pinned ACP reference documents

These are verbatim pinned copies of the upstream Agent Client Protocol (ACP) v2 draft and the prompt delivery RFD that the fork's interface contract in `docs/ACP_FORK_INTERFACE.md` targets. They exist so the target survives upstream edits, or deletion of the personal fork that hosts the RFD. They are not jcode documentation and must not be edited. To change the target, update the contract and re-pin deliberately.
