### Test adaptations (`17b49ed93`)

- `turn_event_channel_terminal_tests::cancellation_dispatch_cannot_signal_a_successor`
  (fork test) used the removed descendant-cancel await as a scheduling seam.
  The idle Stop now completes before any await, so it cannot reach a
  successor. The test asserts that instead of a pending first poll.
- `runtime_ssh_loops_tests::cancelled_session_does_not_restart_for_unfinished_todos`
  (new upstream test) fired shutdown before `run_followups` claimed its turn.
  The fork's turn claim discards a cancel armed before the claim
  (`discard_cancel_armed_before_turn`), so the test now cancels the claimed
  turn, as a Stop during a running turn does. This is a small hunk in an
  upstream test file.
